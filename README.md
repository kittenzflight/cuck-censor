# Site Blocker Extension

A browser extension that blocks explicit websites and NSFW images.

## Features
- Blocks 37+ adult websites
- Automatically detects and covers NSFW images on any webpage
- Lightweight and easy to use

## Installation

### Chrome/Edge/Brave

1. Download this repository:
   - Click the green **"Code"** button above
   - Select **"Download ZIP"**
   - Extract the ZIP file

2. Install the extension:
   - Open Chrome and go to `chrome://extensions/`
   - Enable **"Developer mode"** (toggle in top right)
   - Click **"Load unpacked"**
   - Select the extracted `site-blocker` folder

3. The extension is now active!

## How It Works
- Blocks access to known explicit websites
- Scans images on every webpage for NSFW content
- Covers suspicious images with a dark overlay

## Blocked Sites
The extension blocks 37+ adult websites including major platforms.

## Privacy
All filtering happens locally on your device. No data is sent to external servers.
